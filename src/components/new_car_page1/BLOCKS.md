## Текстовые блоки

### `car-text-block.vue` (textBlock)
**Тип в JSON:** `textBlock`

**Описание:** Блок с заголовком и подзаголовком, текст отображается с золотым градиентом.

**Визуальное представление:**
- Центрированный текст на белом фоне
- Заголовок: крупный шрифт (64px на десктопе, 36px на мобильных) с золотым градиентом
- Подзаголовок: средний шрифт (24px на десктопе, 18px на мобильных) с золотым градиентом
- Минимальная высота: 40vh

**Поля данных:**
- `title` - заголовок (объект с локализацией)
- `subtitle` - подзаголовок (объект с локализацией)

---

### `car-text-simple-block.vue` (textSimpleBlock)
**Тип в JSON:** `textSimpleBlock`

**Описание:** Простой текстовый блок с заголовком, подзаголовком и примечанием. Текст черный на белом фоне.

**Визуальное представление:**
- Центрированный текст на белом фоне
- Заголовок: крупный шрифт (48px на десктопе, 32px на мобильных), черный цвет
- Подзаголовок: средний шрифт (20px на десктопе, 16px на мобильных), серый цвет
- Примечание: мелкий шрифт (14px на десктопе, 12px на мобильных), серый цвет
- Минимальная высота: 10vh

**Поля данных:**
- `title` - заголовок (объект с локализацией)
- `subtitle` - подзаголовок (объект с локализацией, опционально)
- `note` - примечание (объект с локализацией, опционально)

## Медиа блоки

### `car-hero.vue` (heroBlock)
**Тип в JSON:** `heroBlock`

**Описание:** Главный герой-блок страницы с фоновым видео или изображением, заголовком, подзаголовком, кнопками и характеристиками.

**Визуальное представление:**
- Полноэкранный блок с видео или изображением на фоне
- Темный оверлей для читаемости текста
- Заголовок и подзаголовок по центру
- Кнопки действий под текстом
- Характеристики внизу блока (значение + метка)
- Поддерживает адаптивные изображения (desktop/tablet/mobile)

**Поля данных:**
- `video` - путь к видео (приоритет над изображением)
- `image` - объект с путями к изображениям: `{ desktop, tablet, mobile }` или строка
- `title` - заголовок (объект с локализацией)
- `subtitle` - подзаголовок (объект с локализацией)
- `buttons` - массив кнопок: `[{ text, type, style }]`
- `specs` - массив характеристик: `[{ value, label }]`

### `car-video-block.vue` (videoBlock)
**Тип в JSON:** `videoBlock`

**Описание:** Блок с видео и текстом поверх него в верхней части.

**Визуальное представление:**
- Видео на всю ширину блока
- Градиентный оверлей сверху (темный к прозрачному)
- Текст по центру в верхней части видео (12% от верха)
- Заголовок: белый текст (40px на десктопе, 26px на мобильных)
- Подзаголовок: белый текст с прозрачностью (16px на десктопе, 14px на мобильных)
- Видео автопроигрывается, зациклено, без звука

**Поля данных:**
- `video` - путь к видео файлу
- `title` - заголовок (объект с локализацией, опционально)
- `subtitle` - подзаголовок (объект с локализацией, опционально)

### `car-image-text-block.vue` (imageTextBlock)
**Тип в JSON:** `imageTextBlock`

**Описание:** Блок с изображением и текстом рядом. Поддерживает расположение текста слева или справа.

**Визуальное представление:**
- Две колонки: текст и изображение
- По умолчанию текст слева, изображение справа
- Можно инвертировать через `textRight: true`
- Заголовок и список особенностей (features)
- Адаптивный: на мобильных колонки становятся вертикальными

**Поля данных:**
- `image` - путь к изображению (ищется в папке `cards/`)
- `title` - заголовок (объект с локализацией)
- `features` - массив строк особенностей (объекты с локализацией)
- `textRight` - булево значение для размещения текста справа (опционально)

### `car-two-images-block.vue` (twoImagesBlock)
**Тип в JSON:** `twoImagesBlock`

**Описание:** Блок с двумя изображениями рядом друг с другом, каждое с подписью.

**Визуальное представление:**
- Сетка из двух колонок (1fr 1fr)
- Каждое изображение в контейнере с минимальной высотой 400px
- Подпись под каждым изображением
- На мобильных колонки становятся вертикальными (1fr)
- Отступы между изображениями: 40px на десктопе, 32px на мобильных

**Поля данных:**
- `images` - массив объектов: `[{ image, caption }]`
  - `image` - путь к изображению
  - `caption` - подпись (объект с локализацией)

### `car-video-text-block.vue` (videoTextBlock)
**Тип в JSON:** `videoTextBlock`

**Описание:** Блок с сеткой 2x2: два видео и два текстовых блока, чередующиеся.

**Визуальное представление:**
- Сетка 2x2:
  - Верхний левый: видео 1
  - Верхний правый: текстовый блок 1
  - Нижний левый: текстовый блок 2
  - Нижний правый: видео 2
- Текстовые блоки содержат заголовок, список элементов (значение + метка) и примечание
- Видео автопроигрываются, зациклены, без звука
- На мобильных сетка становится вертикальной (1 колонка)

**Поля данных:**
- `video1` - путь к первому видео
- `video2` - путь ко второму видео
- `text1` - объект: `{ title, items: [{ value, label }], note }`
- `text2` - объект: `{ title, items: [{ value, label }], note }`

## Интерактивные блоки

### `car-360-block.vue` (360Block)
**Тип в JSON:** `360Block`

**Описание:** Интерактивный блок с 360-градусным просмотром автомобиля с возможностью выбора цвета.

**Визуальное представление:**
- Большой просмотрщик 360-градусных изображений
- Курсор меняется на специальный курсор 360 при наведении
- Перетаскивание мышью или касанием для вращения
- Внизу селектор цветов с миниатюрами
- Под селектором описание выбранного цвета
- Кадры 360-градусного изображения загружаются динамически

**Поля данных:**
- `colors` - массив объектов цветов: `[{ id, name, images: [массив кадров], description }]`
- `note` - общее примечание (объект с локализацией, опционально)

**Особенности:**
- Поддерживает форматы: `360/${colorId}/frame_${index}.webp` или `${carId}_360_${colorId}_${index}.webp`
- Автоматически определяет количество кадров
- Плавная анимация при перетаскивании

---

### `car-slider-block.vue` (sliderBlock)
**Тип в JSON:** `sliderBlock`

**Описание:** Блок с горизонтальным слайдером изображений.

**Визуальное представление:**
- Заголовок блока
- Горизонтальный слайдер с изображениями
- Стрелки навигации слева и справа (появляются при необходимости)
- Под каждым изображением подпись
- Плавная прокрутка с анимацией
- На мобильных отображается одно изображение, на десктопе может быть несколько видимых

**Поля данных:**
- `title` - заголовок блока (объект с локализацией)
- `slides` - массив объектов: `[{ image, caption }]`
  - `image` - путь к изображению
  - `caption` - подпись (объект с локализацией)

---

### `car-inside-block.vue` (insideBlock)
**Тип в JSON:** `insideBlock`

**Описание:** Блок с интерактивным просмотром интерьера автомобиля с выбором опций.

**Визуальное представление:**
- Большое изображение интерьера (два слоя для плавного перехода)
- Внизу селектор опций интерьера с иконками
- Под селектором заголовок, описание выбранной опции и примечание
- Плавная смена изображений при выборе опции

**Поля данных:**
- `title` - заголовок блока (объект с локализацией)
- `options` - массив объектов: `[{ id, name, image, description }]`
  - `id` - идентификатор опции
  - `name` - название (объект с локализацией)
  - `image` - путь к изображению или объект с путями
  - `description` - описание (объект с локализацией)
- `note` - примечание (объект с локализацией, опционально)

**Особенности:**
- Поддерживает форматы: `inside/inside_${id}.webp` или `${carId}_inside_${id}.webp`
- Поддерживает два слоя изображений для плавного перехода

## Специализированные блоки

### `car-stargate-block.vue` (stargateBlock)
**Тип в JSON:** `stargateBlock`

**Описание:** Блок с фоновым изображением или видео и характеристиками внизу. Поддерживает как изображения, так и видео.

**Визуальное представление:**
- Фоновое изображение или видео на всю ширину
- Темный оверлей для читаемости
- Характеристики внизу по центру
- Каждая характеристика: большое значение и метка под ним
- Разделители между характеристиками (вертикальные линии)
- Белый текст на темном фоне

**Поля данных:**
- `video` - путь к видео (приоритет над изображением, опционально)
- `image` - объект с путями: `{ desktop, tablet, mobile }` или строка (опционально)
- `specs` или `features` - массив объектов: `[{ value, label }]`
  - `value` - значение (объект с локализацией или строка)
  - `label` - метка (объект с локализацией)

**Особенности:**
- Если указано видео, оно отображается вместо изображения
- Если указано изображение, используется адаптивное разрешение
- Если не указано ни то, ни другое, используется fallback `stargate.webp`

### `car-space-block.vue` (spaceBlock)
**Тип в JSON:** `spaceBlock`

**Описание:** Блок с сеткой 2x2 для демонстрации пространства: два изображения и два текстовых блока.

**Визуальное представление:**
- Сетка 2x2:
  - Верхний левый: изображение 1
  - Верхний правый: текстовый блок 1 (заголовок, текст, примечание)
  - Нижний левый: текстовый блок 2 (заголовок, список элементов)
  - Нижний правый: изображение 2
- На мобильных сетка становится вертикальной (1 колонка)

**Поля данных:**
- `image1` - путь к первому изображению
- `image2` - путь ко второму изображению
- `text1` - объект: `{ title, body, note }`
- `text2` - объект: `{ title, items: [{ value, label, description }] }`

### `car-massage-block.vue` (massageBlock)
**Тип в JSON:** `massageBlock`

**Описание:** Блок с информацией о массажной системе, разделенный на секции.

**Визуальное представление:**

- Внутри секции элементы с значениями, метками и описаниями
- Вертикальные разделители между секциями
- Компактный дизайн с небольшими отступами

**Поля данных:**
- `sections` - массив объектов секций: `[{ title, items: [{ value, label, description }] }]`
  - `title` - заголовок секции (объект с локализацией)
  - `items` - массив элементов секции
    - `value` - значение (объект с локализацией или строка)
    - `label` - метка (объект с локализацией)
    - `description` - описание (объект с локализацией, опционально)

### `car-details-block.vue` (detailsBlock)
**Тип в JSON:** `detailsBlock`

**Описание:** Блок с деталями автомобиля в виде карточек разного размера.

**Визуальное представление:**
- Сетка карточек
- Большие карточки (занимают больше места)
- Маленькие карточки (группируются вместе)
- Каждая карточка: изображение, заголовок и описание
- Адаптивный дизайн

**Поля данных:**
- `title` - заголовок блока (объект с локализацией, опционально)
- `items` - массив объектов: `[{ image, title, description, size: 'large' | 'small' }]`
  - `image` - путь к изображению
  - `title` - заголовок карточки (объект с локализацией)
  - `description` - описание (объект с локализацией)
  - `size` - размер карточки: "large" или "small"

**Особенности:**
- Элементы автоматически группируются по размеру
- Большие карточки отображаются первыми, затем маленькие группами

### `car-cards-block.vue` (cardsBlock)
**Тип в JSON:** `cardsBlock`

**Описание:** Блок с карточками в специальной компоновке: одна большая сверху, остальные внизу.

**Визуальное представление:**
- Заголовок блока
- Большая карточка сверху на всю ширину
- Внизу: одна карточка слева и две карточки справа (вертикально)
- Каждая карточка: изображение, заголовок, описание и примечание
- Адаптивный: на мобильных все карточки вертикально

**Поля данных:**
- `title` - заголовок блока (объект с локализацией, опционально)
- `cards` - массив объектов (минимум 1, максимум 4): `[{ image, title, description, note }]`
  - `image` - путь к изображению
  - `title` - заголовок (объект с локализацией)
  - `description` - описание (объект с локализацией)
  - `note` - примечание (объект с локализацией, опционально)

### `car-mvp-block.vue` (mvpBlock)
**Тип в JSON:** `mvpBlock`

**Описание:** Блок с изображением и характеристиками поверх него.

**Визуальное представление:**
- Большое изображение
- Характеристики позиционированы поверх изображения
- Каждая характеристика: большое значение и метка под ним
- Белый текст на темном фоне (или на изображении)

**Поля данных:**
- `title` - заголовок блока (объект с локализацией, опционально)
- `image` - путь к изображению
- `features` - массив объектов: `[{ value, label }]`
  - `value` - значение (строка или число)
  - `label` - метка (объект с локализацией)

## Общие замечания

### Локализация
Все текстовые поля поддерживают локализацию через объекты:
```json
{
  "ua": "Українська версія",
  "en": "English version",
  "uk": "Українська версія" // альтернатива для ua
}
```

Компоненты автоматически определяют активный язык и используют соответствующий перевод.

### Пути к изображениям и видео
- **В development режиме:** `/src/assets/pages/${carId}/...`
- **В production режиме:** `/pages/${carId}/...`

Относительные пути автоматически разрешаются относительно папки автомобиля.

### Адаптивность
Все блоки адаптивны и корректно отображаются на:
- Десктопах (ширина > 876px)
- Планшетах (576px - 876px)
- Мобильных устройствах (< 576px)

### Производительность
- Изображения загружаются с `loading="lazy"` для оптимизации
- Видео автопроигрываются только при необходимости
- Используются оптимизированные форматы (WebP для изображений)
